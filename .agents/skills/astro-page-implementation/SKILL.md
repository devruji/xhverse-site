Implement Astro pages and sections in a way that matches repository patterns and keeps diffs production-grade.

3. Keep styling aligned with current spacing, typography, and visual language.
4. Avoid unrelated refactors.
5. Ensure mobile and desktop layout both remain coherent.
6. Summarize changed files, risks, and verification notes.

# Output

- changed files
- risks / assumptions
- verification notes
