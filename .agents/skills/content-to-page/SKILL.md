# Goal
Convert content ideas into clean, structured, production-ready page sections.

# Rules
1. Keep tone concise, professional, minimal, and credible.
2. Avoid generic startup or marketing language.
3. Prefer clear headings, short support copy, and subtle CTA patterns.
4. Match the xhverse brand style.

# Output
- section structure
- heading ideas
- support copy
- CTA suggestion if relevant
