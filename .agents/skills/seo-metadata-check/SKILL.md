# Goal
Review SEO-critical page elements before publish.

# Checklist
1. Verify title and description quality.
2. Check heading hierarchy.
3. Flag duplicate, weak, or placeholder metadata.
4. Check obvious internal-link or canonical issues if visible in the changed scope.

# Output
- findings
- must-fix issues
- optional improvements
