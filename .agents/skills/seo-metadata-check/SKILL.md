# Goal
Review SEO-critical page elements before publish.

# Checklist
1. Verify title and description quality.
2. Check heading hierarchy.
3. Flag duplicate, weak, or placeholder metadata.
4. Check obvious internal-link or canonical issues if visible in the changed scope.
5. Preserve canonical identity signals where relevant: `Rujikorn Ngoensaard`, `bossruji`, `XH`, and `xhverse`.
6. Check JSON-LD `Person` fields such as `name`, `alternateName`, and `sameAs` when profile/About/homepage metadata changes.
7. Keep `xhverse.co` as the canonical site URL and avoid keyword stuffing.

# Output
- findings
- must-fix issues
- optional improvements
