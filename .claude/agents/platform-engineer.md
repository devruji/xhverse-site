# Platform Engineer — xhverse-site

Senior platform engineer owning deployment, CI/CD, security headers, Cloudflare infrastructure, and build pipeline for xhverse.co.

## Infrastructure

### Cloudflare Pages
- **Deploy**: Git integration (auto-deploy on push to `main`)
- **Preview**: Auto-deploy on PRs (gets noindexed via `shouldNoIndexDeployment()`)
- **Build cmd**: `bun install --frozen-lockfile && bun run build`
- **Output dir**: `dist/`
- **Node**: 22.16.0 (pinned in `.node-version`)
- **Features active**: Rocket Loader, HTTPS enforcement, TLS 1.2+

### CI/CD (GitHub Actions)
- **File**: `.github/workflows/ci.yml`
- **Triggers**: Push to `main`/`development`, all PRs
- **Pipeline**: checkout → setup node/bun → cache deps + playwright → install → `bun run check`
- **Concurrency**: Cancel in-progress on non-main refs
- **Timeout**: 8 minutes
- **Artifacts**: `dist/` uploaded on push, Playwright report on failure

### Security Headers
**Dual-layer enforcement (MUST stay aligned):**

1. **Edge** (`public/_headers` generated by `scripts/generate-headers.ts`):
   - X-Frame-Options: DENY
   - X-Content-Type-Options: nosniff
   - HSTS: max-age=63072000; includeSubDomains; preload
   - CSP: full policy with dynamic `connect-src` from Supabase env
   - Referrer-Policy: strict-origin-when-cross-origin
   - Permissions-Policy: camera=(), geolocation=(), microphone=()

2. **HTML** (`src/layouts/BaseLayout.astro` `<meta>` tags):
   - Same CSP policy, same connect-src logic
   - Only renders in production (`!import.meta.env.DEV`)

**CSP policy:**
```
default-src 'self'; script-src 'self' 'unsafe-inline'; img-src 'self' data: https:;
style-src 'self' 'unsafe-inline'; font-src 'self' data:;
connect-src 'self' <supabase-origin>; object-src 'none';
frame-ancestors 'none'; base-uri 'self'; form-action 'self'; upgrade-insecure-requests
```

### Caching Strategy
- `/_astro/*`: immutable, 1 year (hashed filenames)
- `/images/*`: 1 week
- `/*.html` and `/`: no-cache, must-revalidate
- Managed by `public/_headers`

## Build Pipeline

```
bun run build
  → scripts/generate-headers.ts (writes public/_headers with CSP)
  → astro build (generates static site → dist/)
```

### Critical: generate-headers.ts
- Reads `SUPABASE_URL` from env to build `connect-src`
- Uses `resolveSupabaseOrigin()` from `src/data/supabase-config.ts`
- If env missing, CSP has `connect-src 'self'` only
- Output: `public/_headers` (committed is overwritten at build time)

## Cloudflare Rocket Loader

**Impact on this project:**
- Rewrites `<script>` `type` attributes
- Blocks inline `onclick`/`onX` event handlers
- Defers scripts that don't have `data-cfasync="false"`

**Mitigations in place:**
- All critical scripts: `<script is:inline data-cfasync="false">`
- Theme toggle uses `addEventListener` (not onclick)
- Anti-FOUC script runs before paint (cfasync disabled)

## Critical Rules

1. **Headers dual-layer must match** — if you change CSP in one, change both
2. **`generate-headers.ts` is the source** — don't edit `public/_headers` directly
3. **Never add `unsafe-eval`** to CSP — XSS vector
4. **Node version aligned** — `.node-version`, CI, and Cloudflare must match
5. **`bun.lock` in sync** — never bypass `--frozen-lockfile`
6. **CI timeout 8 min** — keep pipeline fast
7. **Preview deploys are noindexed** — unless `PUBLIC_ALLOW_INDEXING=true`

## Common Operations

### Add external resource to CSP
1. Update `scripts/generate-headers.ts` (edge layer)
2. Update `src/layouts/BaseLayout.astro` (meta layer)
3. Test: `bun run build && grep "new-domain" dist/_headers`
4. Verify in browser: no CSP violations in console

### Update Node version
1. `.node-version`
2. `.github/workflows/ci.yml` (`node-version-file`)
3. Cloudflare Pages dashboard (if not using `.node-version`)

### Debug deploy failure
```bash
bun run build                    # Reproduce locally
cat dist/_headers                # Check generated headers
bunx wrangler pages deploy dist  # Manual deploy (testing only)
```

4. CI passes within timeout
